# 更新记录

### 2026-09-21

- App 0.4.9 与插件 0.4.2 增强接入模型的编码工作约定：重要发现和阻碍及时反馈，进度说明后继续工作，减少长时间只有工具记录、最后才统一回复的情况。
- 引导模型合并相关只读检查、减少重叠读取，遇到输出截断时缩小范围；证据充分后及时收敛，不以提速为由跳过权限和必要验证。实际效果仍取决于所选模型。
- 验证四类接口在先反馈、再调用工具、回传工具结果并继续回答时保留正文和工具数据；不把内部思考改成正文，不改写现有流式转发行为。
- 插件升级至 0.4.1，新增可选的执行型子代理：外部模型可直接修改项目文件、执行命令和运行测试，无需切换主模型或开启挟持模式；默认仍保留只返回修改建议的用法。
- 不限定 DS/GLM，支持选择所有已配置连接及其已选模型；四类接口共用执行能力，模型及上游仍需兼容工具调用，遇到不兼容时不会偷偷换模型或供应商。
- 自动寻找本机原生 Codex，包括桌面版自带程序；执行任务使用独立临时配置，真实供应商 Key 不写入其中，不修改主对话配置。写入须显式授权，命令联网默认关闭。
- 执行结果展示命令状态、退出码和补丁涉及的文件，直接修改不再重复应用。取消或超时会回收执行进程，但可能保留部分文件修改；重叠工作区避免并行写入，需要并行时使用独立工作区。
- 修复部分 Gemini 等转换响应缺少用量字段时导致任务已回答却被判定失败的问题。
- 插件委派和等待默认从 25 秒延长至最多 10 分钟，任务完成立即返回，减少等待期间反复唤醒主模型；有其他工作可做时仍支持立即返回。
- 等待超时后继续使用同一任务，不重复委派或播报未变化的进度；取消等待不会取消后台任务，主动取消任务仍会及时结束等待。
- 同步延长插件宿主超时，避免旧的短超时提前切断长等待。更新插件后需在 Codex 新建对话加载；本次不改变原生子代理等待行为，也不保证具体额度节省比例。

### 2026-09-20

- 更新窗口提供始终可见的「检查最新版本」，支持从旧版本直接升级到最新版；已有下载也可重新检查，同版本完整安装包可复用，检查失败保留已下载包。
- Responses 每个模型可选择自动、上游默认或自定义输出额度；自动模式按当前接口匹配已核实预算，避免遗漏输出参数时沿用较小默认值而截断长回答或工具参数。
- 模型选择列表支持拖拽或方向键排序，保存后同步调整 Codex 模型目录顺序，不改变默认模型身份。
- 已有请求额度优先，未知型号不猜测；压缩请求和返回流保持原样，不重试或伪造完成状态。输出额度与上下文容量分开设置。
- 修复较矮窗口滚动到下拉框后菜单立即收起的问题，模型编辑保存按钮始终可用。
- 上下文按「手动设置 → 已核实的官方容量 → 未知型号默认 256K」生效，模型编辑窗口支持恢复自动，并显示当前容量与压缩阈值。旧的手填值保留，清空后才使用自动规则；官方规格按具体型号维护，不按厂商名称推断新型号。
- 保存、删除、模型修改和模式切换等提示更简短，成功、普通、警告和错误提示统一显示 3 秒后自动收起，鼠标悬停不延长；需要确认的对话框仍等待用户操作。
- 开启挟持模式时同时接管原默认自定义提供商，重启 Codex 后旧对话也经本地网关转发，关闭时恢复原地址、凭据和 WebSocket 设置。
- 图片输入支持按模型自动识别或手动开启、关闭，修复所有模型被声明为仅文字而无法上传图片的问题；保存后重启 Codex 刷新。
- 开启与关闭挟持模式后提示重启 Codex；收到本地请求后显示接入状态，帮助识别旧对话仍沿用原提供商的情况。
- CPA 等上游推荐使用 Responses 透传：切换模型和凭据，仅在缺少额度时补模型输出预算，保留正文、工具数据、JSON 和流式响应，将模型兼容交给上游。
- 不再在透传链路补写思考参数、强制关闭存储、转换标签、缓存思考历史或合成事件；网络断流直接报告传输失败，不自动重试。
- 新连接默认 Responses 透传，旧连接仍保留原接口；在 Responses 与 Chat Completions 之间切换时保留地址和 Key，透传模型隐藏无效的厂商兼容选项。

### 2026-09-17

- 模型可独立选择 Gemini、DeepSeek、Kimi、豆包、MiniMax、GLM 等兼容策略，官方地址自动识别，自定义网关保留 CPA 通用模式。
- 一个 worker 下的多个模型可直接在 Codex 中切换，使用各自的兼容策略和上下文；具体模型使用固定标识，调整 App 默认值不会误切已经选定的模型。旧版连接别名仍可访问。
- 补齐结构化思考和工具回合历史回传，支持 MiniMax 思考拆分、工具签名保留及超长工具名称映射；不支持关闭思考的已知模型会提前提示，不自动重试生成请求。
- 已选模型可独立设置上下文长度，压缩阈值随容量调整；保存后重启 Codex 生效，并保留关闭挟持模式时的原配置恢复。
- 优化外部模型的进度提示要求，并明确识别缺少完成事件的断流，避免将不完整响应当作成功。
- 模型列表增加移除按钮及确认弹窗，手动添加或修正 ID 的模型可从当前连接彻底移除，同时清理显示名称；上游模型移除后保留为未选候选。移除默认模型时自动选用剩余已选模型，删到最后一项会提示选择或添加新的默认模型后再保存；取消和 Esc 均保留原配置。
- 移除连接信息、任务分工和高级设置面板内重复的标题、介绍与分隔线，打开 Tab 后直接显示配置字段，减少纵向占用。
- 删除、退出、模型编辑、插件管理及更新弹窗的文字不再以中文句号结尾；浮动提示与后台返回的错误说明采用相同样式，保留句间标点及版本号、地址中的英文句点。
- 界面文字整体增大一档，覆盖侧栏、表单、模型列表、按钮、弹窗和浮动提示；同步调整按钮与下拉框高度，较窄窗口仍可操作。
- 连接名称取消小写开头、字符类型和 48 字符限制，支持中文、空格、大小写、符号和长名称；仅保留空名称与重名检查。复制保留完整名称，含斜线或百分号的名称也能在 Codex 中正确选择和切换模型，旧连接继续兼容。
- 修改 API 地址或接口类型后，Key 留空继续沿用已保存的 Key；填写新值才替换。原有 Key 环境变量设置保持生效，无需因地址变化而清除。
- 修复开启挟持模式后点击关闭仍无法退出的问题。正常关闭窗口会自动停止挟持模式、取消进行中的模型请求并恢复 Codex 配置，无需再次确认。
- 未保存修改使用与页面一致的白色弹窗，支持继续编辑或放弃修改后退出；恢复失败以浮动提示说明原因，保留窗口和备份，修复后可重试。
- 已选模型可修正实际发给上游的模型 ID，并单独编辑显示名称；修改保留默认身份和其他选择，刷新目录不会覆盖修正结果。保存后重启 Codex 并重新选择修改后的模型；仅改显示名称时不影响实际调用。
- 模型选择合并为统一的可搜索勾选列表，支持全部／已选筛选、行内设置默认和手动添加弹窗；连续勾选保持列表位置，默认模型始终保留，切换默认不移除原已选模型，刷新目录不会丢失手动配置。
- 思考等级改为紧凑按钮，移除重复模型标题与两套下拉／搜索区域；模型列表内部滚动，适配较小窗口。
- 新增「挟持模型列表」：默认模型自动加入，同一连接可额外添加多个模型，从服务目录选取或手动填写；保存并重启 Codex 后可在同一对话中直接切换，不改变插件委派的默认模型。
- 不同连接的同名模型分开显示并使用各自凭据，兼容旧版连接和对话入口。
- 修复删除确认按钮文字与背景同色的问题；保存、删除、更新等操作结果改为顶部白底浮动提示，可主动关闭，错误不会自动消失。
- 移除右上角重复帮助入口和侧栏「本机运行」，将 App 版本移到检查更新窗口。
- 插件管理显示已安装版本、App 附带版本和可更新版本，支持独立检查、下载与安装插件，无需升级或重启 App；拒绝损坏、不兼容更新与旧 App 附带插件的降级覆盖。
- 工作原理改为图片，分别说明两种调用路径、费用来源与 App 运行要求。

- 配置页面采用白底布局、可收起侧栏和四个 Tab，减少展开说明；保存与测试按钮固定在底部，保存按钮使用暖灰色。
- 下拉菜单统一为白底、浅灰选中态和勾选标记，支持方向键、首尾定位、输入检索与 Esc 取消；取消不会修改配置。
- 「模型选择」提供七档思考等级直接点选，切换 Tab 保留草稿。Codex 中手动选择优先于连接默认；四种接口传递相应推理参数，旧配置继续使用服务默认。
- 挟持模式开关放到连接标题旁，切换默认连接有独立入口，侧栏绿色标记实际使用的连接。
- 插件管理、应用更新和帮助独立呈现；连接复制、重命名与删除保留，更新前保护未保存配置。
- 关闭挟持模式后恢复默认模型，同时保留无密钥的停用提供商，旧对话仍可打开。新版 App 会修复旧版遗留的 `Model provider api_subagents not found` 入口，不修改聊天记录；继续使用外部模型时需重新开启模式。
