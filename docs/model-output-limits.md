# 模型输出额度与上下文

核对日期：2026-09-20。这里记录的是火山 Coding Plan 平台规格，不直接套用模型厂商其他平台的额度。

## 官方规格

来源：[火山 Coding Plan 套餐概览](https://docs.volcengine.com/docs/ark/coding-plan-personal-plan-overview?lang=zh)，页面更新于 2026-09-18。下表保留官网的 K 单位；自动请求预算按十进制保守换算（例如 384K → 384000），不宣称是接口精确硬上限。

| 模型 | 上下文窗口 | 最大输出 |
| --- | ---: | ---: |
| DeepSeek V4 Flash / Pro | 1024K | 384K |
| GLM-5.3 / GLM-5.3-Flash | 1024K | 128K |
| Kimi K3 | 1024K | 128K |

## 请求参数的含义

来源：[火山 Chat API](https://docs.volcengine.com/docs/ark/chat-api?lang=zh)，页面更新于 2026-09-17。

- `max_tokens` 的通用默认值为 4096，通常限制回答长度，不含思维链；文档为部分具体版本列出例外，不能跨型号照搬。
- `max_completion_tokens` 限制回答和思维链的总长度，不能与 `max_tokens` 同时设置。该字段支持的型号和参数范围要另行核对，不能直接把型号表中的最大输出值填入。
- 上下文窗口、型号允许的最大输出、接口省略参数时的默认值，以及单次请求选择的输出预算，是不同的设置。

## 配置原则

优先保留客户端明确指定的额度；需要补缺省值时，按实际平台、模型和接口参数分别配置。官方最大值用于校验能力边界，不等于每次请求都应申请该额度。未知型号的 256K 上下文默认值，也不代表默认允许输出 256K。

## App 中的设置

在「模型选择」点击模型行的编辑按钮，可设置该模型的「输出额度」：

- **自动（厂商资料）**：已核实型号使用对应参考预算。直连火山 Coding Plan 地址时自动使用火山表；CPA 等中转地址无法可靠判断实际平台，可手动选择平台。
- **火山 Coding Plan**：按上表中具体型号选择预算。未列出的型号仍保持上游默认。
- **保持上游默认**：不补输出参数，适用于上游自行管理额度的连接。
- **自定义**：指定 128–1000000 的整数 tokens；此输入范围不代表模型支持这么大的输出，请以实际平台为准。

这些设置仅用于 Responses 生成请求。请求缺少 `max_output_tokens`、`max_tokens` 和 `max_completion_tokens` 时，网关才补入 `max_output_tokens`。已有参数（包括 null、零或非法值）原样交给上游校验；压缩请求不加额度。请求正文、工具参数、返回 JSON 和 SSE 不做转换，失败不重试，不合成完成事件。

未知型号不会使用 256K 上下文作为输出预算。插件任务的 `maxTokens` 和其他接口原有设置不受此选项影响。保存后下一次请求生效，无需修改聊天记录；App 升级需重启本地网关。插件同时升级到 0.3.9，以保持新配置字段的读写兼容。

此次修复处理了 Codex 省略输出参数、CPA 转发后沿用上游较小默认值这一条截断路径。它不能消除真实输出超过预算、上下文耗尽或平台独立限制引起的截断。已使用本地模拟和隔离 Codex 验证，未调用真实付费模型。
