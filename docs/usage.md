# 连接与使用

## 配置连接

| Tab | 内容 |
| --- | --- |
| 连接信息 | 调用名称、接口类型、API 地址、Key；重命名也在此处完成 |
| 模型选择 | 拉取模型列表并选择；服务不支持列表时可手动输入 ID |
| 任务分工 | 描述适合委派的工作，帮助 Codex 选择连接 |
| 高级设置 | 流式响应、输出长度、并发和超时 |

连接名称以小写字母开头，只含小写字母、数字、下划线和连字符，最多 48 字符。复制会保存独立副本，其他连接草稿保持不变。删除需要在弹窗中确认。

| 接口 | API 根地址示例 |
| --- | --- |
| OpenAI 兼容 / CPA | 服务提供的 /v1 地址；CPA 常用 `http://127.0.0.1:8317/v1` |
| Responses | `https://api.openai.com/v1`，或支持 Responses 的 CPA 地址 |
| Claude 原生 | `https://api.anthropic.com/v1` |
| Gemini 原生 | `https://generativelanguage.googleapis.com/v1beta` |

测试连接会发送一条简短请求，可能产生少量费用。模型还需要支持工具调用才能完成编码任务；仅通过连通性测试不代表所有能力都兼容。

默认流式接收，不支持流式的服务可切换为普通响应。首个数据默认等待 180 秒，响应空闲默认 120 秒，任务总时限默认 15 分钟。心跳只刷新空闲时间。失败或断流不会由本工具自动重复生成请求。

也可从环境变量读取 Key。该变量需存在于实际请求进程中：挟持模式是桌面 App，插件模式是 Codex 启动的 MCP 进程。插件使用时，将变量名加入已安装插件 `.mcp.json` 的 `env_vars`；升级会保留名单。

## 插件委派

在 Codex 中说明边界，例如：

> 把 utils 目录中批量补中文注释的工作交给 commenter，只读取有关文件。你检查修改片段并运行必要测试。

外部模型只能使用受限文件工具读取项目、提出修改建议；它不能执行命令或直接写入文件。Codex 检查并应用建议。返回默认精简，完整记录保存在本机，需要时再读取。

委派适合重复量较大的明确任务。简单问答和小改动会增加调度成本，流式响应本身也不会减少 token。

## 挟持模式

保存连接后在左侧开启，重启 Codex。模型列表中：

- **跟随 App 选择**：后续请求使用 App 的默认连接，切换 App 连接无需再次重启。
- **连接名 · 模型 ID**：固定使用该连接，可在 Codex 模型列表切换。

左侧绿色「挟持中」标记表示最近一次请求使用的连接；尚无请求时显示默认连接。开启本身不会发送模型生成请求。

本地网关仅监听回环地址，以随机令牌鉴权。CPA SDK 负责 Responses 与其他协议的转换，Codex 的登录信息和本地令牌不会转发给模型服务。原生 Responses 接口兼容性通常更完整，其他协议仍取决于模型的工具能力。当前目录声明文本输入与 32K 上下文；不宣称支持图像或原生网络搜索。非 Responses 服务不支持 /responses/compact，Codex 使用本地上下文压缩。

关闭模式会恢复之前的模型设置，保留其他 Codex 设置的新修改。App 正常关闭前会提醒恢复；异常退出后，下次启动会尝试恢复。若提示托管提供商被手动修改，备份会保留，避免覆盖用户编辑。模式运行时请勿移动数据目录；使用其他 Codex 配置 profile 时，其覆盖项可能优先于此处的默认设置。

主对话内容、工具结果和代码会发送给所选模型服务。两种模式均使用外部 API 独立计费，本工具不读取套餐剩余额度。

## 本机数据

| 内容 | 默认位置 |
| --- | --- |
| 连接与 Key | `%LOCALAPPDATA%\CodexApiSubagents\models.json` |
| 委派记录 | `%LOCALAPPDATA%\CodexApiSubagents\tasks\` |
| Codex 配置备份与模型目录 | `%LOCALAPPDATA%\CodexApiSubagents\codex-*.json` |
| 插件运行程序 | `%LOCALAPPDATA%\CodexApiSubagents\runtime\` |
| 已安装插件 | `%USERPROFILE%\plugins\api-subagents\` |

`API_SUBAGENTS_HOME` 可指定数据目录，`CODEX_HOME` 可指定 Codex 目录。Key 和备份仅保存在本机；Git 与安装包不包含这些数据。备份可能包含原 Codex 配置中的私人字段，应和 Key 一样保管。
