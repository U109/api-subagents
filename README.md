# API Subagents

把批量注释、机械修改、定点调查等明确的重复工作交给自己配置的外部模型，减少 Codex 主模型的阅读和生成。Codex 负责确定任务边界与必要验收，外部模型负责被委派的工作。

2026-09-16：配置页改为四个 Tab，支持已保存连接重命名，侧栏“⋯”提供复制与删除；跨 Tab 保留草稿。已有精简委派、局部修改建议、流式响应和分阶段超时，源码方法均附中文说明。

## 开始使用

从 GitHub 获取的是源码，首次使用前请先按下方“安装和开发”完成依赖安装与构建，再运行这些启动脚本。

1. 双击 **Install.cmd**，注册并安装到 Codex 个人插件目录。
2. 双击 **Configure.cmd**，点击“添加模型”，在 **“连接信息”** 填写调用名称、接口类型、API 地址和 API Key。在 **“模型选择”** 点击 **“拉取模型列表”**，选择默认模型；可输入名称筛选。在 **“任务分工”** 补充擅长与用途，在 **“高级设置”** 调整输出长度和等待时间，最后点击 **“保存配置”**。切换 Tab 不会丢失输入，保存与测试按钮位于表单上方。
3. 在 Codex 新建任务，直接描述目标，例如：**“检查当前项目的登录流程，找出问题并修复，验证相关测试。”** 插件 Skill 被选中后，Codex 会读取模型用途，自行决定分工和调用名称。

调用名称是内部标识，不需要每次在对话中输入。配置保存后对新子任务立即生效，不需要重新安装插件。运行需要 Node.js 20 或更新版本。运行依赖已打包，使用者不需要 npm install、Python、uv、PAL 或其他 Agent CLI。

重命名连接时，在 **“连接信息 → 调用名称”** 修改后保存；原 Key 和各项参数会保留。名称需以小写字母开头，只含小写字母、数字、下划线或横线，最多 48 字符，不能与其他连接重复。

侧栏每个连接的 **“⋯”** 菜单只有 **“复制”** 和 **“删除”**。复制会单独保存目标连接当前已填写完整的草稿，自动生成不重名的 `-copy` 后缀，并保留凭据；副本可独立修改，删除原配置也不会影响副本。复制不会保存其他连接或全局并发数的草稿。

选择删除后，点击 **“确认删除”** 立即生效，无需另点保存；“取消”或 Esc 会关闭确认框。删除只保存目标连接的移除，其他连接尚未保存的编辑会保留在页面中。

## 减少主模型消耗

默认策略是让外部模型替代一部分主模型工作：主模型只提供相关路径、明确要求与验收标准，让外部模型自行阅读文件。适合批量补注释、格式一致的机械修改、定点排查和资料整理。架构判断、含糊需求与最后验收留给主模型；一句话能完成的问答或单行改动不额外调度。

同一任务复用模型列表，相关小改动合成一次委派；等待期间不重复阅读同一批文件，收到结果后只检查修改片段并运行必要检查。不会默认要求第二个模型再完整审查一遍。请在用途说明中标明你选择的经济型模型适合做什么，插件不会按品牌猜价格。

为减少上下文往返，`delegate_task` 默认在一次调用内等待最多 25 秒，短任务直接返回结果；未完成的任务用 `wait_task` 长等待。默认每项任务最多 8 轮，可用 `max_steps` 调整。默认结果最多返回 2000 字符结论与合计 4000 字符的完整修改片段；省略会明确标记，完整结果仍保存在本机，可按需用 `detail: full` 获取。

已有文件的小改动优先使用 `propose_edit`，返回唯一匹配的旧/新片段，不重发整份文件。父模型审查后可执行返回的 `applyCommand`，本地脚本从任务记录读取完整内容并检查原文件 SHA 后应用；还可在命令末尾追加相对路径，只应用已经审查的文件。文件被用户修改、项目不匹配或内容经过脱敏时拒绝覆盖。多文件应用遇到磁盘故障时会报告已完成的路径。

例如一个约 150 KB 文件只改一行，本地测试的工具返回体由 156,418 字节降至约 700 字节。这是返回内容大小，不是 GPT tokens 或额度的实测节省率。插件无法读取或保证 Codex 套餐额度变化，外部模型 API 也有独立费用。流式响应改善等待体验，本身不减少 token 定价。

自动选用取决于 Codex 是否选择并加载该 Skill；这不是拦截每条消息的强制调度器，也不保证每次任务都调用外部 API。若希望某个项目持续遵循这个偏好，可在该项目的 `AGENTS.md` 中加入一次：

```text
对明确、重复且会占用较多阅读或生成量的工作，使用 API Subagents 的 api-workers Skill，选择我允许的外部模型。只给相关路径、要求与验收标准，不先读完整范围、不重复外部模型的调查；默认精简结果，按需检查修改片段并验证。简单问答和单行改动直接处理，尊重我对模型、费用和数据的限制。
```

这条项目规则需要与项目原有要求合并。插件不会自动修改项目或全局 `AGENTS.md`。用户明确指定模型、不使用外部模型或限制费用时，优先遵循用户要求。

## 拉取与选择模型

“默认模型”是当前连接使用的外部模型。模型列表按填写的地址和 Key 实时获取，不使用写死的型号清单；重新拉取、筛选或拉取失败均不会自动替换当前选择。只在点击“保存配置”时保存选择。列表缓存在当前配置页中，修改地址、协议或凭据后会失效。

- OpenAI、Responses 和 CPA：请求 API 根地址下的 `GET /models`。
- Claude：请求 `GET /models`，自动读取后续页。
- Gemini：请求 `GET /models`，自动读取后续页，排除只支持嵌入等非 `generateContent` 功能的模型。

列表请求不发送生成提示词。最多读取 10 页或显示 1000 个模型，总超时 20 秒。部分网关不提供列表接口，此时可点击 **“手动输入”** 填写模型 ID。列表不保证每个型号都支持工具调用，请选择适合本插件的对话模型；“测试连接”仍只验证基础连通性。

接口参考：[OpenAI 模型列表](https://developers.openai.com/api/reference/resources/models/methods/list)、[Claude 模型列表](https://platform.claude.com/docs/en/api/models/list)、[Gemini 模型列表](https://ai.google.dev/api/models)。

## 选择接口

| 选择 | 默认 API 根地址 | 说明 |
| --- | --- | --- |
| OpenAI 兼容 / CPA | `http://127.0.0.1:8317/v1`（示例） | 使用 `/chat/completions`，填网关实际暴露的模型 ID |
| OpenAI Responses | `https://api.openai.com/v1` | 使用 `/responses`；GPT-6 Astra 的工具调用需要此接口 |
| Claude 原生 | `https://api.anthropic.com/v1` | 使用 `/messages` |
| Gemini 原生 | `https://generativelanguage.googleapis.com/v1beta` | 默认使用 `streamGenerateContent?alt=sse` |

CPA 的模型如果只支持 Responses，请选择 OpenAI Responses，将地址改成 CPA 的 `/v1` 地址。不同模型可使用同一个 CPA Key，也可各用官方 Key。模型 ID 必须实际存在，不会根据显示名称自动猜测。

“测试连接”会发送一条简短请求，可能产生少量 API 费用。它只验证基础连接；首次使用仍需验证该模型的工具调用能力。连接测试最多输出 1024 tokens，最长等待 30 秒。

## 流式响应与等待时间

四种接口默认请求 SSE 流式响应，逐块接收文字、推理片段和工具调用参数。只有收到完整结束信息后才执行工具调用；连接中途断开会明确失败，不执行残缺参数。兼容网关若直接返回普通 JSON，也可接收；若网关拒绝流式请求，可在“高级设置 → 响应方式”选择普通响应。插件不会因断流自动重发生成请求。

“高级设置”提供以下等待参数，保存后用于新任务，已有配置自动采用默认值：

| 设置 | 默认值 | 可调范围 |
| --- | --- | --- |
| 首个数据等待时间 | 180 秒 | 10–600 秒 |
| 响应中断等待时间 | 120 秒 | 10–600 秒 |
| 任务总时长上限 | 15 分钟 | 1–60 分钟 |

首次等待包含连接及首个响应数据；仅收到 HTTP 响应头不会结束该等待。开始接收后，每个数据块或 SSE 心跳都会重置中断等待时间，因此正常持续输出的请求可以超过原来的 120 秒单次上限。任务总时长仍约束所有轮次，心跳不能无限延长任务。流式接收有助于及时获取进度，不改变服务端自身的生成速度。

`task_status` 和 `wait_task` 默认只返回紧凑状态；指定 `detail: full` 后，`progress` 包含当前阶段、轮次、请求耗时、已接收字节数、事件数和最近数据时间，不返回未完成的正文或推理内容。失败会指出轮次，并区分 `FIRST_RESPONSE_TIMEOUT`（首个数据超时）、`STREAM_IDLE_TIMEOUT`（接收中断）和 `TASK_TIMEOUT`（总时长上限）。超时任务标记为失败，主动取消标记为取消。

## 使用示例

- “用我配置的经济型模型给这些工具方法补中文注释，你只检查修改片段和语法。”
- “把这三个文件中格式一致的字段迁移交给外部模型，完成后运行相关测试。”
- “列出 API Subagents 中可用的模型。”
- “让 reviewer 审查 API 校验逻辑，让 researcher 分析相关文档，两者并行，最后汇总。”
- “把这个函数的重构交给 worker，检查它的修改建议后再应用并运行测试。”
- “继续刚才的 reviewer 任务，检查你指出的问题是否已经解决。”

工具：`list_models`、`delegate_task`、`task_status`、`wait_task`、`cancel_task`、`configuration_help`。任务在 MCP 服务中后台运行，默认同时 3 个，可在配置页面调整。

## 能力与边界

子 Agent 拥有独立多轮上下文，可以列出、读取、搜索项目文件并提出局部替换或完整文件修改建议。主 Agent 检查、通过本地脚本应用修改并运行测试。子 Agent 不直接修改项目，不具备 shell、浏览器、其他 MCP 工具或继续创建子 Agent 的能力。

文件工具限定在主 Agent 指定的项目目录内，检查路径穿越和符号链接，排除常见凭据文件、`.git`、`.codex`、依赖及生成目录。这是应用层限制，不是操作系统沙箱。单文件最多 200 KB、列表最多 500 项、单任务最多 20 个文件建议、默认 8 轮和 15 分钟。任务时长可在高级设置中调整，达到上限明确返回失败。

文件建议含原内容 SHA-256，供主 Agent 检查并发修改，建议不会自动应用。若建议触发凭据脱敏，会附带 `redacted: true`，主 Agent 需要结合本地原文件处理，不能直接覆盖。续接仅限当前 MCP 进程内已完成的同模型、同项目任务。关闭 Codex/MCP 会停止活动任务，已保存结果可按 ID 读取。

## 数据位置

- 模型配置：`%LOCALAPPDATA%\CodexApiSubagents\models.json`
- 任务结果：`%LOCALAPPDATA%\CodexApiSubagents\tasks\`
- 已安装插件：`%USERPROFILE%\plugins\api-subagents\`
- 个人插件目录：`%USERPROFILE%\.agents\plugins\marketplace.json`

任务和子 Agent 读取的文件会发送给所选服务。Key 保存在本机配置，不打包进插件，不通过模型列表返回；页面对已有 Key 只显示“已保存”。配置文件应留在私人用户目录。任务记录含最终结果和修改建议，不保存完整对话或 API Key；其中包含项目内容，可按需自行清理。

可用 `API_SUBAGENTS_HOME` 指定数据目录。高级配置支持 `apiKeyEnv`；使用时需让 Codex 进程拥有对应环境变量，并在已安装插件 `.mcp.json` 的 `env_vars` 中增加该名称。简单使用推荐直接在页面保存 Key。

配置页只监听 `127.0.0.1` 随机端口，随机会话令牌保护保存和测试操作，30 分钟后关闭。关闭配置进程也可结束服务。

## 安装和开发

安装脚本保留已有个人 marketplace 内容，首次新增前创建备份；同名插件来自其他来源时停止。它复制插件、写入本机 Node 路径并调用 `codex plugin add`。如果 CLI 不可用，可在 Codex Plugins → Personal 中安装。更新时重新执行 Install.cmd，模型配置保留。

双击入口针对 Windows；Node 运行器本身可在其他平台运行，但未提供相应安装脚本。`scripts/install.ps1 -ProfileRoot <测试目录> -SkipCodex` 供隔离测试使用。

源码位于 `src/`，构建文件位于 `dist/`。Git 仓库不包含 `node_modules/`、`dist/`、本机模型配置、密钥和任务记录。克隆或下载源码后，在项目目录运行：

```powershell
npm ci
npm run build
npm test
```

构建完成后双击 **Install.cmd** 安装插件，再双击 **Configure.cmd** 添加自己的模型。修改源码后重新构建；测试读取构建后的 `dist/`，需要先运行 `npm run build`。

配置页面结构在 `config.html`、样式在 `config.css`、交互逻辑在 `config-ui.js`，模型目录适配在 `catalog.mjs`。依赖许可证见 THIRD-PARTY-NOTICES.txt。

测试使用本地模拟 API，不需要真实 Key；真实服务兼容性需用实际账户验证。模拟测试不是实际 API 联调。
