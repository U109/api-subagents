# API Subagents

在一个桌面 App 中配置外部模型，让 Codex 使用你选择的服务。推荐通过 Responses 透传接入 CPA 等上游，也保留 Chat Completions、Claude 和 Gemini 的本地转换。

Windows 10/11 x64 · Go + Wails · 无需 Node.js · 使用系统 WebView2

## 先选一种用法

| 模式 | 适合什么情况 | 如何开启 |
| --- | --- | --- |
| **插件委派** | Codex 负责主任务，将批量注释、机械修改等工作交给低价模型 | 在「插件管理」中安装，在对话中指定任务和连接 |
| **挟持模式** | 希望外部模型直接承担 Codex 主对话，包括 Codex 套餐额度用完时 | 保存连接，打开连接标题旁的「挟持模式」开关 |

挟持模式通过 Codex 自定义模型提供商接入。模型请求使用所选服务的 API，按该服务计费；插件委派仍需要 Codex 主模型参与，不能保证总 token 用量更少。

## 工作原理

![插件委派与挟持模式的调用路径、计费及 App 运行要求](docs/images/how-it-works.png)

两种模式共用本机连接配置，不读取 Codex 套餐剩余额度。退出 App 会自动关闭挟持模式、恢复原模型设置并保留旧对话入口；异常退出后，下次启动会尝试恢复。Key 不随源码或安装包分发。详细说明见 [连接与使用](docs/usage.md)。

## 开始使用

1. 从 [Releases 下载 Windows 安装包](https://github.com/U109/api-subagents/releases/latest)，双击安装并打开。
2. 点击「添加连接」，填写 API 地址、Key；CPA 等支持 Responses 的上游选择「Responses 透传」。在「模型选择」刷新列表，搜索并勾选要在 Codex 中使用的模型，点击行内「设为默认」，选好思考等级后保存。服务未列出的模型可手动添加。
3. 使用插件委派：打开侧栏「插件管理」，点击「安装到 Codex」，然后在 Codex 新建对话。
4. 使用挟持模式：选中已保存连接并开启，**每次开启后完全退出并重启 Codex**。在 Codex 模型列表选择「连接名 · 模型名称」（未命名时显示 ID），或选择「跟随 App 选择」。左侧绿色标识会显示正在使用的连接。

挟持模式运行期间需保持 App 打开。关闭后需重启 Codex，旧对话继续发送前应重新选择原提供商支持的模型；继续使用挟持模型需重新开启。更新模型列表或默认思考等级后，重启 Codex 刷新。普通插件可在 App 关闭后独立运行。

**一个 worker（连接）可以配置多个模型**，共用地址和 Key。一次勾选并保存后，在 Codex 中直接切换「连接名 · 模型名称」，无需回 App 更换默认模型。透传时模型兼容由上游负责，本地仍保留各模型的上下文容量；「跟随 App 选择」才会随 App 默认值变化。

连接名称支持中文、空格和符号，可在「连接信息」中重命名；侧栏「⋯」菜单提供复制和删除。修改地址或接口类型后仍保留原 Key，配置与 Key 保存在本机，更新不会清除。

## 更新

在右上角打开「检查更新」，可查看 App 当前版本，并依次点击「下载 → 重启并更新」。

插件管理单独显示已安装版本与 App 附带版本。点击「检查插件更新 → 更新至…」，即可下载并安装插件，无需更新或重启 App；安装后在 Codex 新建对话。首次安装也可使用 App 附带的插件。

0.2.0 / 0.2.1 需要先从 Releases 手动覆盖安装一次；0.2.2 可直接更新到新版。首次运行缺少 WebView2 时按提示安装微软运行时。安装包目前未签名。

## 最新更新

### 2026-09-20

- 更新窗口提供始终可见的「检查最新版本」，支持从旧版本直接升级到最新版；已有下载也可重新检查，同版本完整安装包可复用，检查失败保留已下载包。
- Responses 每个模型可选择自动、上游默认或自定义输出额度；自动模式按当前接口匹配已核实预算，避免遗漏输出参数时沿用较小默认值而截断长回答或工具参数。
- 模型选择列表支持拖拽或方向键排序，保存后同步调整 Codex 模型目录顺序，不改变默认模型身份。
- 已有请求额度优先，未知型号不猜测；压缩请求和返回流保持原样，不重试或伪造完成状态。输出额度与上下文容量分开设置。
- 修复较矮窗口滚动到下拉框后菜单立即收起的问题，模型编辑保存按钮始终可用。
- 上下文按「手动设置 → 已核实的官方容量 → 未知型号默认 256K」生效，模型编辑窗口支持恢复自动，并显示当前容量与压缩阈值。
- 保存、删除、模型修改和模式切换等提示更简短，统一显示 3 秒后自动收起。
- 开启挟持模式时同时接管原默认自定义提供商，重启 Codex 后旧对话也经本地网关转发，关闭时恢复原地址、凭据和 WebSocket 设置。
- 图片输入支持按模型自动识别或手动开启、关闭，修复所有模型被声明为仅文字而无法上传图片的问题；保存后重启 Codex 刷新。
- 开启与关闭挟持模式后提示重启 Codex；收到本地请求后显示接入状态，帮助识别旧对话仍沿用原提供商的情况。
- CPA 等上游推荐使用 Responses 透传：切换模型和凭据，仅在缺少额度时补模型输出预算，保留正文、工具数据、JSON 和流式响应，将模型兼容交给上游。
- 不再在透传链路补写思考参数、强制关闭存储、转换标签、缓存思考历史或合成事件；网络断流直接报告传输失败，不自动重试。
- 新连接默认 Responses 透传，旧连接仍保留原接口；在 Responses 与 Chat Completions 之间切换时保留地址和 Key，透传模型隐藏无效的厂商兼容选项。

## 从源码安装

克隆仓库或下载 ZIP 并解压后，双击 **`Install.cmd`**。它会自动准备经过校验的 Go 工具链、下载依赖、编译并安装插件。首次运行需要联网，无需手工执行 npm 命令。

双击 **`Configure.cmd`** 打开浏览器配置页。源码入口与桌面 App 共用本机配置；挟持模式在桌面 App 中开启。
