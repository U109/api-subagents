# API Subagents 0.5.10

- App 0.5.10 / 插件 0.5.8 将确认后的新版原型落到正式应用：接入配置、我的连接、用量统计和插件管理统一紧凑页头、官方 Logo、目录图标、计数标签与蓝色选中态，去除重复标题和说明。
- 配置与连接目录重新校准两行文字及图标对齐，未保存状态不再挤动卡片；配置名称默认只读，点击编辑图标后修改，支持回车完成、Escape 撤销，新增配置入口移到目录旁。
- 桌面工作区的模型列表、请求明细和价格配置独立滚动，表头与操作区保持可见；小屏和低横屏仍可自然滚动，不以裁切内容换取固定布局。
- 连接名称与 API 地址分行展示，服务连接与身份验证层级一致；真实测试状态和耗时集中在连接头部，支持取消，地址或凭据变化后不再显示旧测试结论。
- 价格配置按准确模型 ID 合并展示，不再重复列出“连接 + 模型”；连接间普通、Fast 或长上下文价格不同需明确统一，保留隐藏历史费率与价格草稿，改价不重算历史请求。
- 用量工具栏新增清除全部请求统计，操作前必须确认；清除覆盖全部时间和连接，保留连接、接入配置和费率，清除前未完成的请求不会重新写回新统计，清理失败会明确提示。
- 保留模型级 Fast、模型默认项与排序、保存期间继续编辑、请求取消和应用／插件更新等正式能力，不以原型演示逻辑替代真实调用。

升级：通过应用更新安装 0.5.10，或使用 Windows x64 安装包覆盖安装。使用新增清除统计功能前，请在插件管理将插件更新到 0.5.8，并完全退出后重启 Codex；仍运行旧版插件的会话可能继续写入旧账本，新统计不会读取这些记录。切换主对话接入后同样需要完全退出并重启 Codex。

本机连接、Key、Codex 配置备份、任务记录、用量账本、原型及构建工具不进入源码提交或安装包；模型测试只使用本地模拟接口。
