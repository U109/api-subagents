模型选择改为统一的搜索勾选列表，并支持修正实际发送给上游的模型 ID。

- 一个列表完成搜索、连续勾选、只看已选和设置默认模型，无需反复打开下拉框。
- 服务返回的模型 ID 不正确时，点击已选模型行内的铅笔，在「上游模型 ID」填写正确值；修改后会用于实际请求。
- 「显示名称」独立控制 App 与 Codex 列表文字，可自定义或恢复默认，不代替上游模型 ID。
- 修改 ID 保留默认身份与其他选择；刷新服务列表不会覆盖修正结果，重复 ID 与无效输入会被拦截。
- 思考等级和较矮窗口的布局更紧凑，手动添加与编辑使用弹窗，减少上下滚动。

修改模型 ID 后，请保存配置、重启 Codex，并重新选择更新后的模型。仅修改显示名称时，实际调用与旧对话路由保持不变。

App 与独立插件均更新至 0.3.4。升级保留本机连接与 Key；使用插件委派时，可在「插件管理」更新插件并在 Codex 新建对话。
