发布 App 0.4.10，附带插件 0.4.3，补齐 max / ultra 思考等级。

- 设置、配置保存和 Codex 模型目录增加 max、ultra，不再只能选择到 xhigh。
- 通用接口保留收到的等级；受限厂商接口沿用最高档位，预算式接口沿用 xhigh 上限并遵守输出长度限制。
- 本地模拟测试确认，Codex CLI 0.155.0-alpha.16 可以列出 max / ultra，但选择 ultra 时发送的 reasoning.effort 为 max。插件不会将收到的 max 猜测还原成 ultra；上游支持需单独确认。
- 同时包含上一版本之后的错误反馈修复：Responses 兼容网关返回非标准完成事件时仍可正常结束，上游失败、HTTP 错误和连接错误保留有限的具体原因。

升级：在 App「检查更新」中安装 0.4.10，或使用本页安装包覆盖安装。更新后重新开启挟持模式以刷新模型目录，再完全退出并重启 Codex。插件用户可独立更新至 0.4.3，并在 Codex 新建对话加载。

max / ultra 需要支持字符串推理档位的新版 Codex；目录只声明可传递参数，不保证模型支持或实际推理强度。本次不自动修改已保存的默认等级，不增加付费探测或自动重试。本机连接、Key、Codex 配置备份、任务记录及构建工具不进入发布包。
