# API Subagents 0.5.8

- 按确认的统一工作区原型实现正式界面，覆盖接入配置、我的连接、用量统计、插件管理、使用帮助与弹窗；统一侧栏和主从列表，基础字号调整为 16px，保持窄屏可用。
- 默认模型采用蓝色星标，模型拖动、默认标签、操作表头与删除按钮对齐接入配置；用量趋势优先使用蓝、绿、黄。
- 新增用量统计的概览、分析、请求明细和价格统计，可按时间、连接、模型与来源筛选。主对话接入、两类子代理、图片生成及连接测试写入本地账本，连接测试默认不混入业务总览；缺失用量不补零，也不反推升级前的消耗。
- 支持保存模型费率和查看费用估算，请求保留开始时的费率，修改价格不改写历史；缺少定价或必要用量时费用保持未知，真实费用以供应商账单为准。
- 保存连接和接入配置时仍可继续编辑，稍后返回的结果不会覆盖新修改；刷新模型或测试连接时修改地址、协议或凭据，不会混入旧结果。
- 费率草稿跨页签和页面保留，关闭程序时保护未保存修改；外部修改提示核对或重新载入，保存当前模型不会删除历史费率。保留已有接入开关、配置恢复、请求取消及应用／插件更新能力。

升级：在 App 的「应用更新」安装 0.5.8，或使用本页 Windows x64 安装包覆盖安装。插件可在「插件管理」独立更新至 0.5.6；更新后在 Codex 新建对话加载。主对话接入开关后需完全退出并重启 Codex。

用量数据保存在本机，不保存提示词、回答、真实 Key、授权头或上游错误正文。本机连接、Key、Codex 配置备份、任务记录、用量账本、界面原型及构建工具不进入源码提交或安装包。模型及生图调用仍按用户选择的上游服务计费。
