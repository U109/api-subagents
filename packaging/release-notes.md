发布 App 0.4.8，附带插件 0.4.1，新增通用执行型子代理。

- 外部模型可直接修改项目文件、执行命令和运行测试，无需切换主对话模型或开启挟持模式；默认仍保留只返回修改建议的用法。
- 不限定 DS/GLM：所有已配置连接及其已选模型均可选择，支持 Responses、Chat Completions、Anthropic Messages 和 Gemini。模型及上游仍需兼容工具调用，不会自动换模型或供应商。
- 执行模式需要本机原生 Codex。插件自动查找 PATH 和 Codex Desktop 自带程序；每个执行任务使用独立临时配置，真实供应商 Key 不写入其中，不修改主对话配置。
- 默认只读、命令联网关闭。直接写入须显式授权；不提供全盘访问或自动审批。取消、失败和超时可能留下部分修改，需检查实际 diff 与命令退出码，不能重复应用。
- 返回命令状态、退出码和补丁路径；同一插件进程避免重叠工作区并行写入。执行任务暂不支持续接，可在原任务结束后基于实际工作区派发新任务。
- 修复部分转换响应缺少用量字段导致 Codex 错判任务失败的问题。保留最多 10 分钟的委派等待及同一任务继续等待机制。
- 本机连接、Key、Codex 配置备份、任务记录和构建工具不进入源码提交或安装包。

升级：可在 App 的「应用更新」中安装 0.4.8，或使用本页安装包覆盖安装。已有 App 用户也可在「插件管理」中独立更新插件至 0.4.1。更新插件后在 Codex 新建对话；已有对话不会自动切换到新工具进程。

使用示例：使用 API Subagents 的执行模式，让指定连接中的模型直接完成修改并运行测试；允许修改当前项目，不允许联网，保留已有改动，并在结束后检查实际 diff 和测试退出码。
