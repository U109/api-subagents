发布 App 0.5.4，附带插件 0.5.2，改善临时上游故障引起的断链。

- 普通 Responses 请求在尚未向 Codex 返回响应头或内容时遇到 502/503，会进行有限恢复；包括通过普通生成请求发起的自动压缩，不再首次临时失败就立即结束。
- 最多追加三次尝试，默认等待 2、15、45 秒；遵守更长的有效 Retry-After，超过一分钟的冷却保留原错误，不擅自提前重试。
- 所有尝试共享原首包等待与总时限，取消或关闭网关立即停止；成功流逐字透传，持续失败原样保留最后的错误、HTTP 状态和请求 ID。
- 已开始的流、连接错误、认证和额度错误不重放；Worker 和独立 compact 接口仍保持单次请求，不增加隐藏调用或自动重跑工具。
- 保留最近请求诊断、已发布的界面与配置恢复功能；附带插件仍为 0.5.2。

升级：通过 App 的应用更新安装，或使用本页 Windows 安装包覆盖安装。安装前保存工作并退出 App；重新开启挟持模式后完全退出并重启 Codex。插件更新后在 Codex 新建对话。

本机连接、Key、Codex 配置备份、任务记录和构建工具不进入源码提交或安装包。
