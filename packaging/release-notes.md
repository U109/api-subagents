# API Subagents 0.5.7

- 按确认原型统一接入配置、我的连接、插件管理和帮助页面，采用中性色与一致的图标、标签、弹窗；侧栏不再展开连接，窄屏与长文本保持自适应。
- 接入配置独立组合连接并选择 Codex 模型及默认项，不修改连接的模型；保存与启用分开，重新开启沿用上次明确启用的配置。
- 模型支持鼠标、触屏与键盘拖动排序；上下文设置移至模型操作，可关闭覆盖使用原生容量。默认采用明确容量与 256K 中的较小值，未知容量不猜测。
- 保存、放弃、刷新和测试只作用于当前连接，保留其他草稿；更新检查显示旋转等待，支持下载进度、取消、自动检查和跳过版本。
- 切换、删除与退出继续保护 Codex 配置；固定接入模型范围，旧凭据不会被发送至修改后的服务地址。保留旧对话接入、有限流式恢复、脱敏请求诊断和独立图片生成。

升级：在 App 的「应用更新」安装 0.5.7，或使用本页安装包覆盖安装。插件可在「插件管理」独立更新至 0.5.5；更新后在 Codex 新建对话加载。主对话接入开关后需完全退出并重启 Codex。

本机连接、Key、Codex 配置备份、任务记录、界面原型及构建工具不进入源码提交或安装包。模型及生图调用仍按用户选择的上游服务计费。
