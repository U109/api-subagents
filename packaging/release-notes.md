Go + Wails 桌面版与「挟持模式」。

- 桌面改用系统 WebView2，安装包大幅缩小，无需 Node.js。
- 新增挟持模式：让配置的外部模型直接承担 Codex 主对话；左侧显示开启状态与当前连接，Codex 模型列表支持切换。
- 支持 Responses、OpenAI 兼容 / CPA、Claude 和 Gemini，流式返回文字与工具调用。
- 关闭模式恢复原 Codex 模型设置，保留其他配置修改；模型连接和 Key 继续保存在本机。
- 保留配置 Tab、一键安装插件与应用更新；Install.cmd 自动准备 Go、依赖和编译。
- 按功能重新组织源码，补充方法注释，精简 README。

首次开启挟持模式后请重启 Codex，并在使用期间保持 App 打开。外部模型服务单独计费。

0.2.2 可通过应用内更新升级；0.2.0 / 0.2.1 需手动下载覆盖安装。安装包目前未签名。
