# API Subagents 0.5.9

- App 0.5.9 / 插件 0.5.7 新增模型级 Fast：按模型独立开关，默认关闭；我的连接与接入配置中，已开启的模型显示闪电标识，取消编辑不生效，保存连接后才提交。
- Fast 接入实际请求，支持 Responses／兼容 Chat 的 Priority 档位与 Claude 原生 Fast；普通模型不会继承其他模型的开关，压缩请求不附加 Fast。上游明确降级时按普通费率估算，是否提速仍取决于供应商与账号。
- 内置 67 条截至 2026-10-14 核对的 OpenAI、Claude、Gemini 与 DeepSeek 默认报价，普通与 Fast 价格独立，支持官网已列出的长上下文费率；未知私有型号不猜价。DeepSeek 使用官网高峰参考价，Gemini 使用付费标准文本费率，实际费用以供应商账单为准。
- 价格页只显示已保存连接中已选择的模型；可编辑普通、Fast 与长上下文价格，保留高精度小数和隐藏历史费率，改价不重算历史请求。
- 移除 Ultra 可选档位，旧配置自动迁移到 Max，不因升级丢失连接。
- 接入配置列表摘要用省略号，未保存连接等校验改为提示弹窗；成功提示置顶，不可用模型使用带提示的红色图标，桌面工作区按实际可用高度自适应。
- 用量筛选统一为可键盘操作的单选菜单，图表提示跟随指针并避让边缘；图例只显示有记录的模型，Token 拆分只显示有值项目，清理重复状态文案并优化更新弹窗间距。

升级：通过应用更新安装 0.5.9，或使用 Windows x64 安装包覆盖安装。插件可在插件管理独立更新至 0.5.7；更新后在 Codex 新建对话加载。切换主对话接入后需完全退出并重启 Codex。

本机连接、Key、Codex 配置备份、任务记录、用量账本、原型及构建工具不进入源码提交或安装包；模型测试只使用本地模拟接口。
