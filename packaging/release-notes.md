# API Subagents 0.5.6

- App 0.5.6 按最终确认原型统一连接卡片、四个设置页签、字体、图标与弹窗；点击卡片选择连接，管理入口独立，移除重复标题、协议标签和冗余说明。
- 保存与放弃修改只作用于当前连接，不影响其他连接草稿；已保存连接可继续接入主对话，退出时仍保护所有未保存修改。
- 模型支持搜索、全部／已选筛选、批量勾选、星标默认、拖动与键盘排序、移除撤销和独立编辑；模型名称及表头更易阅读。
- 新连接的自定义高级参数覆盖默认关闭，开启后可设置输出、流式响应与超时；关闭不清空已填写参数，旧配置继续沿用原值。超时范围直接显示在字段名称旁。
- 应用与插件更新可取消检查或下载；应用更新保留自动检查偏好及跳过版本选择。关闭更新弹窗不会取消下载，也不会自动安装。
- 「最近请求」移至「使用帮助 → 查看最近请求」，继续提供脱敏状态与请求 ID；保留已发布的旧对话接入、配置恢复、有限流式恢复与图片生成功能。

升级：在 App 的「应用更新」安装 0.5.6，或使用本页安装包覆盖安装。插件可在「插件管理」独立更新至 0.5.4；更新后在 Codex 新建对话加载。主对话接入开关后需完全退出并重启 Codex。

本机连接、Key、Codex 配置备份、任务记录、界面原型及构建工具不进入源码提交或安装包。模型及生图调用仍按用户选择的上游服务计费。
