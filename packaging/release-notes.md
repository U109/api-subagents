新增挟持模型列表，支持在 Codex 中切换多个外部模型；插件可独立更新。

- 修复「确认删除」按钮文字不可见。
- 「模型选择」新增挟持模型列表，从服务目录选取或手动添加，同一连接支持多个模型。保存并重启 Codex 后，可在同一对话内直接切换，不改变插件委派的默认模型。
- 宽屏并排展示默认设置和挟持列表，保留旧版连接别名与对话入口；同名模型在不同连接中使用各自的地址和 Key。
- 保存、复制、删除、更新等结果改为顶部白底提示，可手动关闭；错误保留到关闭。
- 去除右上角重复帮助按钮和侧栏「本机运行」，App 版本移到更新窗口。
- 插件窗口显示实际安装版本、App 附带版本及可更新版本；可独立检查、下载并安装插件，无需更新或重启 App。
- 插件更新校验文件、版本与兼容性，保留现有连接与 Key，旧 App 不会覆盖更高版本插件。
- README 使用图片说明插件委派与挟持模式的调用路径和计费。

首次使用独立插件更新，需要先升级 App 至本版。升级后可在「插件管理」单独更新插件，再在 Codex 新建对话。已有连接与 Key 会保留。
